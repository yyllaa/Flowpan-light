# 更新日志

## 1.0.2 — 2026-11-16

- 管理页按内容高度显示，少量记录的分页紧跟列表，不再固定撑满屏幕。
- 记录较多时限制内容区高度，只滚动列表；筛选、批量操作与分页保持可用。
- 接入公共页面 SDK 的自适应尺寸合同，窄屏页头说明与操作同排。
- 配合新版宿主，真实生成任务和字节进度接入任务中心，查询动作不再挤占最近记录。

## 1.0.1 — 2026-11-16

- 管理页使用紧凑记录行，状态与文件大小、账号放在同一信息区，右侧操作统一对齐。
- 手机搜索与搜索按钮同排，账号和状态筛选并排，按钮统一 36px 高、13px 字号；批量按钮等宽，勾选记录后显示。
- 手机记录操作与元信息同排，压缩说明和勾选栏留白，长文件名最多显示两行并保留完整标题。
- 记录列表独立滚动，筛选和分页保持可见；已选链接按需展开。
- 已暂停任务显示已读取进度，保留原生成、停止、继续、授权与删除确认流程。

## 1.0.0 — 2026-11-16

- 文件浏览器单文件和批量选择生成 ED2K。
- 独立 ED2K 管理页支持搜索、筛选、复制、导出、继续、停止和删除记录。
- 宿主连续流读取、持久分块检查点、结果复用及账号限流暂停。
- 其他插件按账号和目录授权查询已有结果。
