# 115 ED2K

安装并启用插件，在授权范围中选择 115 账号和目录。文件浏览器的单文件菜单和批量选择栏会显示“生成 ED2K”；目录和其他提供者不显示该入口。一次选择最多 50 个文件。

导航中的“ED2K 管理”显示生成记录，支持按账号、状态、名称、路径和哈希筛选，勾选后复制或导出 TXT。生成读取完整文件内容，采用单条连续流；宿主一次处理一个文件，已有结果直接复用。可停止和继续，重启后由用户手动继续。遇到账号错误或限流时暂停，停止期间保留完整分块检查点。删除记录保留云盘文件。

其他插件可通过公共 SDK 的 `ListED2K` 和 `ED2KTask` 查询已有结果，声明 `ed2k.read`，并授权相应账号和目录。生成需要 `ed2k.generate`；停止和删除需要 `ed2k.manage`。源文件、账号、目录、插件启用状态和授权由宿主校验，插件不接触 Cookie 和临时下载地址。结果保存于宿主插件数据目录的 `ed2k/library.db`。

算法固定为给定 115 向量：9,728,000 字节分块、MD4 摘要、多块摘要合并、不增加空尾块。空文件直接生成空 MD4。默认串行读取，最大文件 1 TiB，等待队列最多 200 个；这些是宿主资源上限，不代表服务端风控阈值。

需要先更新主程序至 `2026.11.16-ed2k` 或包含同等合同的版本。构建：在仓库根目录运行 `python plugins/build.py --plugin ed2k --host /实际路径/flowpan --go go --out dist/ed2k`。构建执行发布包校验，页面资产随插件 ZIP 分发。

## 1.0.1 管理页

手机按钮统一为 36px 高、13px 字号，复制和删除与文件元信息同排；未勾选时收起批量操作。记录列表独立滚动，筛选和分页保持可见，长文件名最多两行并保留完整标题。更新日志随清单与插件一起提供。

本次配套主程序为 `2026.11.16-ed2k-ui`，保留单文件、单连接连续读取，每个文件复用 256 KiB 缓冲；生成、授权、停止和断点继续沿用原流程。
