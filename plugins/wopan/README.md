# 联通云盘原生网盘插件

- 插件 ID：`storage-wopan`；网盘提供者：`wopan`；版本：`0.2.2`。
- 清单声明 `definition.network.proxy="direct"`，接口与宿主处理的文件传输均直连，不使用项目 HTTP 代理。
- 独立 WASM ZIP，不需要独立进程或镜像，不注册为默认插件源，也不自动启用。
- 安装并启用后，通过项目原生账号中心添加联通云盘账号；文件浏览、STRM、有声书和上传任务使用同一来源及能力目录。

## 已实现的能力

| 能力 | 实现 |
| --- | --- |
| 登录 | 仅联通云盘扫码；PNG 二维码由宿主原生账号中心展示，凭据自动保存，无需手填 |
| 账号 | 远端稳定 UID、多账号隔离、加密保存、字段脱敏 |
| 续期 | 服务端登录失效后续期一次；新凭据持久保存，不改变原来源授权版本 |
| 文件 | 个人空间分页、文件信息、Range 读取、原始签名直链、建目录、重命名、删除至回收站、移动 |
| FUSE | 可写挂载所需的删除与移动均已接入；主程序需包含移动后引用与 inode 同步修复 |
| 分享 | 原生转存下载自动识别联通分享文案、账号与目录选择；官方 H5 查询与一次接收，不重复提交未知回执 |
| 上传 | 宿主计算 SHA256；先秒传、未命中再按 16 MiB 分片流式上传；宿主进度和检查点 |

本版只声明上述能力。家庭空间、复制、CAS 和批量清理均未开放，不把其他网盘的专用协议当作联通云盘实现。

## 安装

1. 使用包含本版网盘宿主扩展的 Flowpan（`StorageUploadStep.hash_algorithm/save_checkpoint`、multipart 上传及业务续期持久化）。主程序还需包含本次 FUSE 移动后引用与 inode 同步修复；先更新主程序再更新插件。
2. 在插件管理导入 `storage-wopan-0.2.2.zip` 并启用。
3. 在原生账号中心选择“联通云盘”，添加账号后点击“生成二维码”扫码登录。账号名称仅为显示名，可单独保存，无需填写 Token。
4. 在文件浏览选择该账号；STRM、上传任务按该来源选择目录。

## 请求和上传行为

- 每页列表只读取该目录的一页，最多 500 条，不在插件中递归遍历或聚合全部页面。501 条文件的两页用 2 次正常列表请求。
- 文件 ID 保留列表 ID、FID 和父目录链，已有 FID 的取链不先重扫目录。签名查询字符串保持原样。
- 读取接口遇到 `9999` 最多退避重试一次；写入接口不因 `9999` 自动重放。写操作保留 800 ms 节奏。
- SHA256 由宿主读取本地文件计算；文件字节不会进入 JSON/WASM。分片表单由宿主生成 boundary 和 Content-Length。
- 秒传请求前先持久化检查点；分片请求前同样持久化。未知回执、保存检查点失败不自动改走全量上传，也不盲目重发。
- 当前所给协议没有查询已接收分片的接口。回执丢失后的重试会要求核对远端，而不是声称已支持可靠断点续传。
- 上传确认后额外核对返回 FID、文件名和大小，目录尚未确认时保留错误，不报告成功或自动重复上传。

## 构建和测试

需要 Go 1.25+ 和 Python 3，无需主程序源码。在本目录执行：

    go test ./...

在仓库根目录执行：

    python plugins/build.py --plugin wopan --out dist/wopan

构建包只包含 manifest.json 与 plugin.wasm。共用 SDK 通过本目录 go.mod 的相对引用提供。

## 协议来源和验证

`internal/wopan` 从用户提供的 `wopan-go-src/wopan` 机械复制，原文件哈希见 `upstream-sha256.json`。适配 Token 续期回调、扫码参数编码、只读重试；建目录和重命名保留错误且不重放未知结果，追加单页/账号/上传元数据桥接；原目录保持不变。

回归测试使用本地 TLS 协议服务，实际加载并执行 WASM，校验签名、AES 请求、二维码、双账号、分页、字节 Range、续期、秒传、分片、配额和未知回执。本轮实际联网分享查询已确认返回用户提供的音频；协议模拟测试与真实账号测试分别记录，不将模拟吞吐当作实际网速。
