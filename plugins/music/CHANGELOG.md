# 更新日志

## 1.0.3 · 2026-11-17

- 音乐来源使用宿主统一账号目录，显示已授权的网盘及本机目录，不再固定为 115。
- 音乐目录接入项目共用选择器，支持浏览和手填；切换来源时清空旧目录，保留网盘文件夹 ID 原值。
- 声明 ui.file-picker 功能要求，旧宿主会明确指出缺项；音源、缓存、请求间隔、定时和回写逻辑保持。

## 1.0.2 · 2026-11-17

- 同步新版独立 SDK，与声明式能力层宿主兼容。
- 保留按实际工具、媒体及分段任务合同检查兼容性；无需额外申请插件间调用权限。
- 音源、匹配、请求间隔、缓存、定时和校验回写流程保持。

## 1.0.1 · 2026-11-17

- 清单声明实际调用的工具、分段任务、封面、歌词、校验回写与页面能力，并补齐任务状态查询所需 task.read 权限。
- 安装前显示具体缺项，兼容时无需按主程序构建号逐次适配。
- 音乐源、匹配、缓存、间隔及写入策略保持原有处理流程。

## 1.0.0 · 2026-11-17

- 本地与网盘音乐共用暂存、读取、匹配、无损封装及校验回写流程。
- 网易、QQ、iTunes、MusicBrainz 来源，文件名模板与简繁转换复用。
- 标签、内嵌封面及歌词，低置信度候选确认。
- 串行批处理、持久化请求间隔、查询和封面缓存、文件指纹增量。
- 定时任务、同一任务的分段执行与进度、断点继续及未知回写核验。
- 网盘原件备份、替换与恢复；本地保留原件输出副本。
- 独立音乐刮削页面，适配桌面及手机。

依赖宿主 2026.11.17-music-runtime 提供的公共分段任务、二进制图片与音乐媒体合同。
