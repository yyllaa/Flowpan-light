# 音乐刮削 1.0.1

本地目录与网盘音乐共用一条处理链：先扫描目录，逐首暂存到宿主磁盘，读取现有标签，匹配音乐，使用 FFmpeg 复制音频包并写入标签、封面和歌词，最后由宿主回写并校验结果。插件 WASM 不接收整首音频，不把 3000 首全部下载后再处理。

1.0.1 使用声明式能力合同，需要宿主 **2026.11.17-plugin-contract** 或满足清单 `requires` 的后续版本。市场和安装器会在下载、启用之前指出缺少的工具、功能及运行上限。以后音源、规则、动作及页面更新由插件独立发布；引入新的宿主原语时再声明对应功能版本。在设置的依赖下载中安装 FFmpeg、FFprobe。插件包不包含主程序和媒体工具。

## 配置与运行

1. 导入或从插件市场安装插件，启用后授权音乐所在账号、目录。处理本地音乐时授权对应本机目录；容器中填写容器可见路径。
2. 在插件设置的“音乐来源”选择一个账号。“音乐目录”填写网盘文件夹 ID 或本机绝对目录。递归处理子目录，单批最多 10000 首、5000 个目录。
3. 首选音源默认网易 → QQ → iTunes；也可指定单一音源或 MusicBrainz。文件名默认按 `@2 - @1` 提取艺术家、标题，只填补文件内部缺失信息。标题、艺术家精确规范化匹配，并参考专辑和时长；版本不符和歧义条目留待确认。
4. 默认只补缺失标签，保留已有值。“更新已确认标签”允许以确认的候选更新标签；源没有的数据不会清空原值。
5. 默认保留原件并输出带 `(flowpan-copy-...)` 的副本；网盘还支持“备份原件后替换”。本地当前使用副本方式。插件会跳过自身生成的副本、备份和中间文件。
6. 在音乐刮削页面开始、停止、继续，查看本轮结果并确认候选。定时规则使用宿主六段 cron，例如每天 03:00 为 `0 0 3 * * *`。未完成批次不会被定时任务覆盖。

## 3000 首的稳定处理

- 先扫描再写入，避免上传的新文件干扰本轮分页。每轮使用固定的账号、目录和策略快照。
- 一次只处理一首；完整音频位于宿主磁盘暂存区，封装时需要原文件加输出文件的磁盘空间。音频包复制，标签修改不转码。
- 文件指纹包含来源、ID、版本、时间、大小、哈希等返回字段，策略未变且文件未变时，后续运行跳过下载、查询和上传。完整标签在“只补缺失”模式可直接跳过音乐源查询。低置信度结果同样复用，确认或文件/策略变化后再处理。
- 标题和艺术家相同的查询共用缓存；有效搜索与歌词缓存 30 天，未命中 6 小时。封面缓存 7 天、最多 64 个，文件缓存及时释放，源的冷却状态持久化。
- 网盘操作默认间隔 3 秒，可设为 2–60 秒；宿主的账号级等待仍生效。网易/QQ 请求至少间隔 3 秒，iTunes 4 秒，MusicBrainz 2 秒。此间隔不构成免风控承诺。403/429 尊重 Retry-After，缺省冷却 15 分钟；网络异常、5xx、空响应指数退避，连续三次失败暂停。
- 长批次拆成宿主可持久化的分段调用，同一个任务 ID 更新进度。正常等待可在重启后继续；中断或待核验状态通过“继续”读取已保存回执。查询只保留在插件详细记录，任务中心呈现实际批次。

官方参考：[Apple Search API](https://performance-partners.apple.com/search-api) 建议约 20 请求/分钟；[MusicBrainz](https://musicbrainz.org/doc/MusicBrainz_API/Rate_Limiting) 规定单客户端不超过 1 请求/秒。网易与 QQ 的公开接口会变化，插件单独维护对应解析器。

## 替换、备份与恢复

网盘替换使用现有宿主 `files.publish`：先上传并校验新文件，再核对原文件快照，将原件改为 `(flowpan-backup-...)`，最后把新文件改为原名称。此过程包含多个网盘操作，文件 ID 会变化。原件备份保留，可在记录中“恢复原件”，恢复时保留刮削结果。

上传待核验时暂停，不自动再次上传。停止会停止批次分段；已经交给宿主的当前单文件操作会保留回执，继续时先核验该操作。完成后释放本地暂存和封装输出；任务账本、封面缓存以及显式保留的网盘备份继续保留。

## 格式与边界

标签处理支持 MP3、FLAC、M4A、M4B、OGG、Opus、WAV；嵌入新封面支持 MP3、FLAC、M4A、M4B。JPEG/PNG 封面最大 512 KiB、4096×4096；内嵌歌词最大 16 KiB。APE、DSF、DFF 暂不进入处理队列。多音轨文件不自动挑选音轨，留待确认。

复用提供源码中的 `filenamerel` 文件名模板和 `chineseconv` 简繁转换；音源查询、匹配、批处理、封装和云盘回写由本插件与宿主公共工具实现。未复用参考目录中的原生加密 DLL、登录或更新程序。网易 weapi 使用 Go 标准库实现。

## 开发

在插件模块中运行 `go test ./...`；公共仓库运行 `python plugins/build.py --plugin music --host FLOWPAN_EXECUTABLE --out dist/music`。`manifest.json` 声明权限、定时任务、页面与更新日志；本插件之外的插件也可以使用新增公共合同。

自动测试包含 3000 首模拟文件、重复查询缓存、第二轮增量、429 冷却、未知上传回执和断点继续。真实账号样本与模拟规模测试应分别报告，模拟 3000 首不代表对真实账号运行了 3000 次上传。
