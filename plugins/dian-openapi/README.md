# 癫影 OpenAPI 插件

插件 ID：`resource-dian-openapi`。与浏览器版 `resource-dian` 分开安装，配置、密钥、运行记录和定时任务按插件 ID 独立保存；不会作为浏览器版的更新覆盖安装。

版本 1.3.7，仅使用 OpenAPI V2。在项目中导入插件，填写个人中心生成的 OpenAPI Key，保存并启用。此版本要求宿主提供 `sdk.call`、动作选项、动作分组、作品选择器和表格结果界面，请与对应新版 Flowpan 一起使用。

清单声明 `definition.network.proxy="project"`，请求统一使用项目设置中的 HTTP 代理；未配置代理时显示配置提示。请与支持网络策略声明的新版宿主配套使用。

## 使用

- 资源：输入作品名，选择带封面的 TMDB 作品，再查询和解锁。微信等项目交互渠道沿用同一资源合同，解锁链接回到项目转存流程。
- 资源筛选：画质、视频编码、HDR、中文字幕、片源、音轨、帧率和体积使用普通表单；剧集可填写季数，留空不限，0 为特别篇。点击查询或应用筛选后读取一页，每页 50 条；修改条件和重置不自动请求，翻页保留已应用的条件。
- 签到：立即签到旁选择普通签到或幸运签到，再点击立即签到；默认普通签到，选择本身不提交请求。幸运签到提交前单独确认，与普通签到共用当天次数和回执；定时签到仍使用普通签到。
- 扩展功能：账号资料与额度、鉴权头像、资源筛选分页、虚拟缓存文件、TMDB/SHA1 查重、115 分享码查重、RSS 选项和游标查询、发布分享、开发者用量。
- 运行记录：查看结果、响应和失败信息；大响应的完整内容保留在首次运行记录。

扩展功能使用普通表单，不要求填写 JSON：

- 发布分享：搜索并选择作品，支持 115 分享链接或同类磁力 / ED2K 批量链接；SHA1 每行一项；清晰度、格式、片源、编码、HDR、音轨、字幕通过选项填写。剧集范围和补充信息折叠展示，特别篇季数 0 会保留。发布前展示冻结的参数摘要并再次确认。
- SHA1 查重：选择作品后粘贴 SHA1，每行一项，自动去重并校验 40 位十六进制格式。
- 分享查重：支持完整 115 链接或分享码，结果直接显示是否已发布。
- RSS：作品类型和清晰度支持多选，分类和地区每行一项；读取下一批沿用本次条件，修改条件后需重新查询。
- 虚拟缓存、资源筛选、RSS 和开发者用量使用可滚动表格；支持的分页接口提供上一页 / 下一页。账号资料、积分和发布回执直接展示，原始响应默认收起。
- 各扩展页分别保留未提交输入；切换、编辑和选择作品不会自行提交接口请求。

普通资源查询支持 movie/tv；剧集不指定季数查询全部季，传 0 表示特别篇。RSS 只读取候选，发布、解锁和转存分别确认。

接口仍受站点账号与 SDK 授权约束：RSS 需要站点开启 RSS 权限；开发者用量只允许该 SDK 所属开发者使用自己的 Key，12 小时最多一次。页面保留真实错误，不把拒绝或超时显示为成功。

## 回执和请求控制

同一 Key 的作品搜索缓存 10 分钟；普通签到与幸运签到按上海自然日共用回执；已解锁结果与已发布分享保留 30 天；扩展只读查询缓存 5 分钟；开发者用量按 Key 复用 12 小时。不同 Key、季数、分页和筛选条件隔离。

资源筛选每次只查询当前页，刷新可重新读取该页。缓存保留可操作的资源和分页信息；超出存储限额的大页完整返回，不用空回执替代资源。

提交写入前保存检查点。网络中断、验签失败及服务端 5xx 的结果保留待核验，避免重复提交；已验签的 4xx 拒绝允许手动重试。插件不会自动重放结果不明的写入。

## 公开代码与宿主分工

此目录只包含业务适配、界面声明、通用 RPC 调用和测试。私有站点 SDK 位于闭源宿主，公开插件不包含其源码、密封包或开发者凭据；用户 Key 由宿主保存并注入 SDK，插件只接收业务结果与不可逆账号指纹。网络请求使用项目 HTTP 代理，不启动浏览器，也不读取用户密码。

宿主逐次检查插件启用状态、`sdk.call` 权限、SDK 声明及工具授权，固定站点和操作白名单；health/migrate/probe 不调用 SDK。发布分享、解锁和幸运签到同时受宿主确认约束。RE0 独立运行。

## 构建

本目录通过 go.mod 引用仓库中的通用 SDK，无需主程序源码。在本目录执行：

```sh
go test ./...
```

在仓库根目录构建可导入的插件包：

```sh
python plugins/build.py --plugin dian-openapi --out dist/openapi
```

运行包只包含 manifest.json 和 WASM。修改清单权限、版本和 SDK 声明时，需要同步宿主能力要求。

## 从本仓库安装与构建

添加统一插件源后选择“癫影 OpenAPI”，不要使用浏览器版的“更新”入口。支持本版能力的宿主需先配置 HTTP 代理，再填写自己的 OpenAPI Key。浏览器版的账号、密码、会话与签到记录不会自动迁移。

在本目录运行 go test ./...；在仓库根目录运行 python plugins/build.py --plugin dian-openapi --out dist/openapi。公开构建仅引用通用 SDK，私有癫影 SDK 不随源码和 WASM 分发。
