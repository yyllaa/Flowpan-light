# 前端布局与验收

Flowpan 沿用现有 Vue 页面、CSS 和公共组件。界面调整优先修改已有规则，避免给同一组件重复叠加覆盖样式。

## 公共样式入口

| 内容 | 文件 | 维护方式 |
| --- | --- | --- |
| 字体、颜色、尺寸变量 | `web/assets/styles/shell.css` | 使用已有 `--ui-*`、`--font-*` 和 `--space-*` 变量 |
| 公共控件 | `web/assets/styles/controls.css` | 按钮、输入框和选择器沿用共用规则 |
| 响应式布局 | `web/assets/styles/responsive.css` | 检查页面宽度与滚动区域，不靠隐藏主要信息解决溢出 |
| 既有页面兼容规则 | `web/assets/styles/compatibility.css` | 在对应规则处修正，不为单次调整新建一层覆盖 |
| 插件弹窗与键盘交互 | `web/assets/features/plugin/framework.js`、`framework.css` | 复用 Dialog、Workspace 等组件 |
| 插件运行记录 | `web/assets/features/plugin/extensions.js`、`extensions.css` | 所有插件复用 Jobs，保持相同的列与状态展示 |

现有页面底色为 `--ui-page`，卡片使用 `--ui-surface`，次级区域使用 `--ui-surface-soft`。正文、辅助文字与边框分别使用 `--ui-text`、`--ui-muted`、`--ui-border`。沿用现有字体栈，不因界面优化引入在线字体请求。

## 已确认的视觉方向（2026-11-10）

用户选择浅色、蓝色重点、清爽紧凑。底色使用 `#f3f6fb`，主要按钮使用 `--ui-primary-bg`（`#2563eb`）和白色文字，悬停与按下分别使用对应的 primary 变量；`--ui-action-*` 保留给浅蓝选中态和次级操作，不能把图标背景一起改成实心蓝色。成功、失败和警告继续使用各自语义色。

页面主标题为 22px，表单与列表正文维持 12–13px。导航选中使用浅蓝实底，普通卡片用边框分组，不叠加渐变或悬浮阴影。输入、目标目录、提交动作按阅读顺序分区，避免每个字段再套一张白色卡片。

转存页面在 1000px 及以上并排显示输入区与目标区；640–999px 把两个网盘目标并排放在输入区下方；更窄时纵向排列。统计栏桌面五列、手机三列两行，不缩小正文或隐藏主要按钮来增加密度。

`tests/browser/console-theme.js` 接入浏览器回归入口，使用已配置双网盘的隔离数据，验证五种宽度下的目标分区、手机统计栏、主操作与悬停颜色、文字对比度、焦点和插件主按钮一致性。

## 布局规则

- 同一列表中标题起点、正文起点、状态与操作列保持一致；名称变长或状态变化时，其他行的操作位置保持稳定。
- 插件记录的状态占固定列，标题与说明共享文字起点；计划触发信息另行排列。长标题换行，错误摘要最多两行，详情保留完整内容。
- 记录的日期与耗时允许换行，手机端仍显示耗时。操作列保留“详情”等文字，窄屏操作按钮最小高度为 44px。
- 窄屏将次级信息移到下一行，保留主要操作；长目录或名称应有换行、详情或可访问的完整文本。
- 弹窗内容超出视口时由弹窗正文滚动，底部操作可以滚动到达。Tab 和 Shift+Tab 在弹窗的可见、可用控件内循环，包含文本框与链接；关闭后回到原来的焦点。
- 颜色、边框、阴影等交互反馈可以过渡。不要用 `transition: all` 让宽度、高度或内边距跟随内容、视口变化做动画。
- 修改资源后同步更新 `web/index.html` 或 CSS 导入处的缓存版本，避免验证到旧资源。
- 业务提示使用项目内组件，表单使用 `novalidate`。不改变现有中文文案含义。

## 验收

先确认问题在浏览器中出现，再做对应修改。至少检查桌面、平板、390px 和 320px；涉及插件记录时同时检查成功、运行中、失败、长标题、长错误、长耗时与短屏滚动。

```powershell
node scripts/check-frontend.cjs
node scripts/check-browser.cjs
```

浏览器检查启动隔离接口夹具，加载真实页面脚本与样式。它验证布局和交互，不代替 NAS、外部插件站点或网盘接口的真实业务测试。

`tests/browser/ui-polish.js` 已接入浏览器检查入口，覆盖 RE0、115 签到、癫影与通用第三方插件宿主卡片的运行记录；夹具使用模拟任务数据，不执行真实签到。检查内容包含列对齐、长耗时、窄屏触控高度、短屏详情、底部操作、尺寸过渡及 Tab 循环。

## 插件配置统一对齐（2026-11-10）

第三方 schema 字段统一由 ConfigForm 渲染。桌面标签与控件同排，标签、输入和开关各自沿固定列对齐；手机输入标签上置，开关与标签仍保持同排。密钥状态提示放在输入框下方，清除操作和输入框同排等高，保存期间禁用，保留空值留存、null 清除的接口语义。

布尔字段不再套独立大底板。账号组、目录列表和只读路径占满表单宽度；目录列表保持多行高度，不能被单行输入框高度规则覆盖。日志使用统一的时间与正文起点，长内容可换行，刷新保留可见文字。

`tests/browser/plugin-ui-layout.js` 检查 10 个插件入口、配置/资源/详情/记录/日志和管理四个标签页，在 1440、1024、768、600、390、320px 下检查水平溢出、控件与文字对齐，并验证条件字段、草稿、错误、密钥清除、保存禁用和短屏操作可达。与宿主能力目录和授权弹窗回归一并接入 `scripts/check-browser.cjs`。界面改动不能只验证运行记录，也必须覆盖真实配置字段。

## 网盘插件的通用展示规则（2026-11-11）

网盘入口必须依据注册目录的 provider ID、name 和可选图标生成；第三方 ID 是不透明字符串，不把“非 115”解释成 139，也不按联通或其他插件名写分支。115/139 的旧业务 key 仅在对应业务边界转换，展示组件不发请求、不改账号和任务。

- 网盘切换统一使用 `FlowpanProviderUI.Switcher`，账号卡片、挂载卡片、文件传输来源统一使用 `FlowpanProviderUI.Mark`。公共脚本先于消费它的功能模块加载。
- 图标占位固定 24×24；账号卡片可统一放大到 40×40。紧凑记录中的图标统一缩小为 16×16。品牌图采用 contain，不拉伸。图标未声明、地址无效或加载失败时都显示同规格云盘图标，不回退成纯文字或其他网盘品牌。当前图标只接受宿主同源 /assets/ 下的 SVG/PNG/WebP 资源；插件协议尚未提供图片时无需伪造链接。
- 切换按钮等宽 116px，桌面高度 40px、窄屏触控高度 44px。名称单行省略，title 保留全名；图标与文字垂直居中，选中/禁用/键盘焦点状态由公共样式控制。
- 多网盘保持一行，在切换栏内部横向滚动，不撑宽页面。选中项自动进入可视区。手机上账号与公共操作另排一行，避免挤压入口。方向键及 Home/End 跳过禁用项，选择 key 不随显示名称或排序变化。
- 缺失账号或元数据时显示“网盘/原账号”，只有已经确认的提供者才显示品牌名称；目录选择器继续使用统一文件夹图标，不给文件夹误套品牌。未声明的业务能力继续按能力目录控制，不因显示入口就假定支持转存、删除或上传。

`npm run check:providers` 使用真实页面和隔离接口夹具，覆盖 3 个/8 个提供者、长名称、缺失/失效图片、1440/768/390/320px、鼠标与键盘切换，并回归原生网盘的账号、文件、STRM、整理、有声书和挂载入口，以及未来网盘的整理/转存记录图标。`tests/browser/provider-ui.js` 也纳入浏览器总回归；`ui-pages-audit.js` 继续覆盖全部 14 个导航页和整理子页。验收只读布局阶段必须没有 API 写入，不用真实网盘请求充当视觉测试。

### 网盘账号表单与状态规范

原生账号中心的网盘插件统一由 `FlowpanPluginAccounts` 渲染。插件仅声明 `storage.fields` 和 `login_methods`，不提交 HTML、页面组件、布局参数或独立样式。后续插件继续使用同一渲染器与 `provider-plugin.css`，不得按提供者 ID 增加专用表单分支。

- 字段按声明顺序展示。支持 text、url、secret、number、boolean、select；宿主账号名称在前，账号操作与登录区在后。桌面标签列固定 132px、控件列自适应，控件高 38px；600px 及以下采用上下排列、44px 控件。开关保持标签与勾选框同行，说明占下一行，不把说明塞进开关横行。
- 输入、下拉框、密钥组合、登录下拉与按钮共享高度和边界；密钥的“清空”按钮保持在输入框右侧。长标签自然换行，长说明和连续字符串在本字段内部换行。窄屏操作采用两列，不以大块留白换取对齐。
- 标签通过 for/id 关联控件；必填、错误和说明通过 aria 属性关联。必填校验失败不写入，首个错误滚入可视区并取得焦点；修改对应字段清除该字段的错误。数字 0 与布尔 false 保留原值。
- 配置读取期间禁用切换与编辑，读取失败只显示错误与“重新读取”，不显示空白可保存表单。保存失败保留草稿并恢复操作。切换账号清除前一账号的草稿、密钥占位与字段错误；账号标题状态以当前账号为准，网盘入口仍按该提供者的所有账号汇总。
- 已存密钥只显示占位，留空保留；“清空”保持显式清除语义。登录方式只来自声明，二维码与登录反馈复用宿主显示，登录期间提供“取消登录”，取消或关闭停止该会话。空账号状态只开放添加入口，不残留其他提供者的字段或登录方式。
- 只有一种登录方式时不显示方式选择器。声明 `login_methods: ["qrcode"]` 的网盘复用移动云盘的原生扫码布局：顶部账号和显示名、二维码框、状态与同一操作区，空状态及删除确认也沿用原生组件。账号名称仅为显示名，“保存”只更新名称，不提交认证设置；登录只通过二维码，重新生成会取消旧会话。此规则按声明生效，适用于后续扫码网盘。

`tests/browser/qrcode-accounts.js` 对比移动云盘与联通、未来扫码网盘在四档宽度下的实际布局和控件样式，覆盖重新生成、取消、改名、确认、读取失败、删除失败与空状态。

`tests/browser/provider-accounts.js` 纳入 `check:providers` 与浏览器总回归，用不同字段组合的未来网盘验证四档宽度、长标签/说明、二维码取消、必填焦点、420px 短屏、失败草稿、读取失败重试、账号状态切换、空账号与新建后的独立字段，以及 Tab/Shift+Tab 顺序。新增网盘 UI 必须通过此规范；供应商协议和真实账号仍按其独立集成测试验证。


网盘账号的外部 API 配置由宿主统一渲染，不要求插件声明 UI 或认证字段。启用开关、独立 Token、权限、调用地址及保存操作保持原生布局；窄屏 Token 与生成按钮保持同行及相同高度。切换账号或关闭时清理草稿和待回传结果，配置读取失败时禁用写入并提供重试。测试 `plugin-external-api.js` 覆盖扫码与表单网盘、两个账号、四档宽度、独立密钥、读取/保存失败及关闭不保存。


## 网盘扩展表单统一规范（2026-11-12）

账号与 STRM、自动上传、自动整理、有声书、挂载的附加设置统一由 `web/assets/ui/storage-form.js` 和 `storage-form.css` 渲染。插件声明六种数据字段、默认值、分组、条件显示、只读信息和动态选项；宿主负责对齐、间距、控件、状态与校验，不允许供应商自行注入样式或组件。协议示例见[网盘插件接入](网盘插件接入.md#账号与任务附加设置2026-11-12)。

桌面保持 132px 标签列和自适应控件列；600px 以下输入上下排列且高 44px，布尔项保持同行。扫码区与附加表单分隔清楚；小屏扫码操作采用三列、360px 以下两列，按钮至少 40px，不横向裁切。无字段时不增加空白区域。只读值自然换行，长路径不撑开页面。

动态选项显示读取、失败、重试与旧值失效状态，不后台轮询；切换账号或依赖后丢弃旧响应。保存时锁定重复提交，失败后解除禁用，再将首个错误字段聚焦；错误与说明分别关联 aria-describedby，必填使用 aria-required。页面引用共用组件，禁止复制一套品牌专用表单。

`tests/browser/storage-ui.js` 覆盖扫码附加设置、版本依赖、只读状态、失败重试、切换账号、五类任务原生接入，以及 1440/768/390/320px 对齐与边界；与现有账号、扫码、提供者切换测试共同运行。

## 工作台与插件中心（2026-11-15）

本轮在现有浅色蓝色界面中调整信息层级，继续使用原有路由、业务入口、图标及目录选择器。

- 桌面侧栏按工作台、文件处理、媒体服务、插件扩展分组。“任务整理”改为“上传任务”，路径仍为 `/task-organize`。860px 及以下底栏固定为仪表盘、文件浏览、转存下载、自动整理、更多；“更多”按组列出所有原生模块和插件声明的页面，并保留账号、其他设置、日志入口。
- 仪表盘不再显示与任务中心重复的“当前工作”，顶部任务入口打开统一任务中心。STRM、字幕、API、FUSE 与 CPU、内存、存储、网络共八张卡片放在同一网格直接显示，统一卡片样式、列宽和间距，不单独设置“系统指标”分组或折叠。任务中心读取原模块记录；转存和整理各最多 200 条，插件和下载各 100 条，不宣称完整历史。局部读取失败时提示失败模块并保留它的旧记录；登出、切换身份与隐藏页面会清理或停止刷新。共享上传记录按任务 ID 去重。
- 插件中心统一搜索名称、说明和 ID，可筛选全部、已启用、待配置、有更新、异常。新版数量同步侧栏、仪表盘、列表卡片和管理入口；版本与来源判断继续使用原合同。插件管理在共享弹窗打开，启停和授权保留直接操作，日志、回滚、卸载等次级操作收进“更多”。空结果提供清除筛选，加载与失败提供状态及重试。
