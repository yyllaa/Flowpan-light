# 插件目录缓存修复（2026-11-17）

旧版宿主读取新版插件目录时，会在持久化清单中丢失当时尚未识别的字段。
升级宿主后，如果插件源返回 HTTP 304，旧清单仍会保留，导致安装校验报错：
`plugin package integrity check failed: package manifest does not match catalog`。

本次重新发布目录文件，使现有 HTTP 校验器失效；所有插件版本、清单、下载地址和包 SHA-256 均保持一致。
已经使用 `2026.11.17-plugin-providers` 的用户，在插件管理中刷新插件源后重新安装即可。
音乐插件仍为 1.0.2，无需卸载其他插件。

后续宿主版本 `2026.11.17-plugin-catalog-cache` 将插件源的缓存校验器与实际宿主合同绑定。
没有合同记录或合同发生变化时，首次刷新重新下载并解析完整目录；后续刷新仍使用 ETag 和 Last-Modified。
刷新失败不标记缓存有效，不改已安装插件和插件数据，包哈希与清单一致性检查保持启用。
