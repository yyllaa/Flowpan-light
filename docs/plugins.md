# 外部插件使用

外部插件由用户选择安装和启用，浏览器、代理、FFmpeg、转存、整理、任务进度及通知等能力由 Flowpan 宿主按授权统一提供。插件使用宿主能力，不需要另起浏览器镜像。

## 添加来源与安装

1. 打开“辅助插件 → 插件管理 → 插件源”。
2. 手动添加下列地址并刷新。
3. 切到“插件市场”，选择需要的插件，确认安装信息及申请的能力。
4. 在已安装插件中配置账号、授权范围并启用。

```text
https://github.com/yyllaa/Flowpan-light/tree/main/plugins
```

项目不自动添加外部插件源。一个来源可以列出多个插件，刷新来源只更新可选目录，不会批量安装或启用。

需要离线导入时，在“插件市场”的“本地插件包”入口选择已取得的插件 ZIP。“插件源”页面管理来源，“已安装”页面管理安装状态。

## 浏览器与网络

使用依赖浏览器的插件前，在“其他设置 → 浏览器”下载组件，并检查是否就绪。项目提供下载源切换、更新及状态维护；Linux 环境还应按页面状态处理运行依赖。

网络代理在项目“其他设置”中保存。容器应能访问所填代理地址，不能直接用容器内的 `127.0.0.1` 指代宿主机。GitHub Token 用于宿主相关 GitHub 请求，插件通过通用网络能力不会取得这个 Token。

浏览器与 FFmpeg 由宿主分开下载，保存在 `/config/runtime` 下。插件升级不会要求每个插件重新打包一份浏览器。

## 癫影

当前来源提供 [癫影插件](../plugins/dian/README.md)，用于资源查询、解锁与每日签到。

在插件配置中保存账号，检查连接。资源页面输入影视名称，选择电影或剧集，再选择搜索得到的具体作品，随后查看对应资源。搜索需要先选作品，名称查询与资源查询分两步完成。

解锁前查看资源信息并确认操作；返回链接后，可交由项目转存入口继续处理，再按已配置规则整理。解锁消耗及可用资源以站点实际返回为准。

## 运行记录与日志

运行记录用于查看每次动作的状态、时间和结果；日志用于排查动作中的详细过程与错误。插件页的记录与项目转存、整理任务各自对应所在环节，转存结果还需查看项目任务。

## 更新与卸载

更新前刷新所用来源，在插件管理中查看可用版本。已安装插件的更新会检查原来源；需要更换来源时，先卸载并保留数据，再从选定来源重新安装。

卸载时可选择数据处理方式：

| 选择 | 结果 |
| --- | --- |
| 默认保留数据 | 移除插件安装，保留配置、私有数据和登录状态，重新安装后可继续使用。 |
| 同时移除插件数据 | 连同该插件配置、私有数据和登录状态一起清理。 |

各插件分别保存自己的配置、授权与私有数据。主程序升级沿用 `/config` 时保留这些数据；卸载插件不会代替撤销已经提交给项目的转存或整理任务。
