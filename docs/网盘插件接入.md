# 外部网盘插件接入

本文说明如何把另一个网盘做成独立 WASM 插件，并让它像内置网盘一样出现在 Flowpan 的账号中心、文件浏览和各业务页面。插件包只提供网盘协议适配器；账号、来源、缓存失效、业务任务和界面由 Flowpan 宿主统一管理，不需要另做一个服务或镜像。

## 接入后的范围

安装并启用一个声明了 `storage` 的插件后，宿主会动态注册它的网盘提供者。只要账号已经登录并且来源可用，它会自动出现在：

- 账号中心：按插件声明的字段创建多个独立账号，支持 Token、二维码等登录方式；密钥在宿主加密存储，表单只显示“已设置，留空保留”。
- 文件浏览：使用来源根目录和不透明文件 ID 浏览、分页、读取、取链及能力允许的写操作。
- STRM：选择该账号和云端根目录，生成和播放地址复用项目的来源、缓存和任务生命周期。
- 自动整理：待整理、已存在、失败、冗余目录使用该来源的目录选择器；提交时再次检查账号和能力。
- 有声书：书库目录、扫描和播放使用同一来源。
- FUSE 挂载：只读或可写能力按声明开启，挂载目录按来源独立保存。
- 下载完成自动上传：目标账号和目录使用统一来源选择器，上传进度进入“任务整理”。

插件不需要修改以上页面的前端注册表。宿主从 `/api/storage/plugins`、`/api/storage/providers` 和各业务返回的 `providers/sources/accounts` 动态生成控件；不安装插件时不会出现额外入口，也不会默认添加插件源或账号。

## 最小清单

清单顶层和 `definition` 同时声明权限与网盘合同。下面是模板的核心部分：

```json
{
  "schema_version": 1,
  "id": "sample-drive",
  "version": "1.0.0",
  "name": "示例网盘",
  "runtime": {"kind": "wasm", "module": "bin/plugin.wasm"},
  "permissions": ["storage.provider", "http.fetch", "log.write"],
  "definition": {
    "schema_version": 2,
    "api_version": "1",
    "id": "sample-drive",
    "version": "1.0.0",
    "name": "示例网盘",
    "runtime": "wasm",
    "config_version": 1,
    "permissions": ["storage.provider", "http.fetch", "log.write"],
    "http_hosts": ["storage.example.com"],
    "storage": {
      "id": "sampledrive",
      "name": "示例网盘",
      "login_methods": ["token", "qrcode"],
      "fields": [
        {"key": "endpoint", "label": "接口地址", "type": "url", "required": true},
        {"key": "token", "label": "Token", "type": "secret", "required": true}
      ],
      "capabilities": ["list", "stat", "read", "link", "upload", "mkdir", "rename", "delete", "copy", "move", "refresh"]
    }
  }
}
```

`storage.id` 是小写字母开头、最长 64 个字符的稳定提供者 ID，不能使用内置的 `p115` 或 `p139`。`definition.id` 是插件 ID，两者可以不同，但发布后都不要随意变更。提供者至少声明 `list`、`stat` 和一种登录方式；未声明的能力不会出现在账号和业务请求中。`http_hosts` 必须列出插件通过 `http.fetch` 访问的 HTTPS 主机。

账号字段支持 `text`、`secret`、`url`、`number`、`boolean` 和 `select`。字段键、选项值和标签必须唯一且稳定；秘密字段不会写入页面响应，也不会进入普通运行记录。供应商自定义字段校验放在插件的 `configure` 处理内，宿主先做类型、必填和权限校验。

### 账号 UI 合同

网盘插件的原生账号界面由宿主统一生成，遵守 [前端 UI 规范](archive/frontend-ui.md#网盘账号表单与状态规范)。插件不携带账号页面 HTML/CSS，也不需要给文件浏览、STRM、自动整理等页面另写界面。

- `fields` 数组决定顺序；`key` 是保存与错误定位的稳定键，不用标签代替。`label` 是简短字段名，较长的解释放在 `hint`。两者均作为纯文本渲染。
- `required` 声明必填；`number` 的 0 和 `boolean` 的 false 是有效输入。`select` 必须提供稳定的 value 和显示 label，宿主不会把显示文案当保存值。
- `secret` 字段使用统一密钥控件，读取只返回 `secrets[key]` 是否存在，不能把已有密钥放回 values、hint 或 placeholder；留空保留，null 显式清除。
- `login_methods` 只决定可选登录方式和顺序；qrcode、credentials、token、cookie 使用宿主通用名称，其他方法显示其声明 ID。附加字段支持 default、group、visible_when、read_only、options_source 和 depends_on；尺寸、组件与布局统一由宿主控制。
- 仅扫码网盘声明 `login_methods: ["qrcode"]`；没有附加设置时使用 `fields: []`。宿主复用移动云盘的原生账号与二维码布局，不生成 Token 输入框或冗余方式选择器；显示名保存仅更新账号名称，不触发认证配置；扫码返回的凭据通过加密 credentials 保存，不能把内部凭据重新声明成用户填写项。联通云盘 0.1.1 使用此合同。
- 启用状态、当前账号的登录状态、空状态、加载/失败重试、字段校验、登录二维码与取消操作都由宿主管理，插件返回业务状态和简洁消息即可。

开发后运行 `npm run check:frontend` 与 `npm run check:providers`；浏览器验收包括 1440/768/390/320px、长字段说明和短屏键盘操作。测试夹具会自动注册未内置的提供者，不依赖具体品牌。

## Go/WASI 处理器

导出 SDK 后，插件用 `pluginwasm.Handlers.Storage` 接收宿主创建的 `StorageCall`：

```go
func main() {
    pluginwasm.Serve(pluginwasm.Handlers{Storage: storageCall})
}

func storageCall(inv pluginwasm.Invocation) (pluginapi.Result, error) {
    call := inv.Request.Storage
    if call == nil { return pluginapi.Result{}, errors.New("缺少网盘调用") }
    // 按 call.Operation 调供应商接口，结果通过 StorageResult 返回。
    return pluginwasm.StorageResult(result), nil
}
```

`StorageCall` 的 `Operation`、`Account`、`SourceID`、`Settings`、`Credentials`、`Session` 和 `Params` 都由宿主生成。插件动作、网页请求或用户输入不能自行构造宿主调用，也不能直接取得其他账号的密钥。模板 `plugins/examples/storage-http/main.go` 用一个 HTTPS JSON 端点演示了转发方式；实际插件应替换为供应商协议，不要保留示例域名。

### 操作合同

| 操作 | 结果 | 说明 |
| --- | --- | --- |
| `configure` | `StorageAuth` | 校验设置，可返回已确认的身份、根目录和凭据 |
| `login.begin` / `login.poll` | `StorageAuth` | 二维码或设备授权；`Session` 只回传给同一账号的下一次轮询 |
| `verify` / `refresh` | `StorageAuth` | 确认身份、根目录和有效期；身份改变会让旧来源失效 |
| `list` | `StoragePage` | 按根目录或 `ParentID` 分页，使用 `NextCursor`，不要遍历无关目录 |
| `stat` | `StorageEntry` | 返回指定不透明 ID 的实际类型、父目录、大小和版本 |
| `read` | `StorageLink` | 读取由宿主代理；插件只返回受限 HTTPS 链接和必要请求头 |
| `link` | `StorageLink` | 返回播放或下载直链和过期时间 |
| `mkdir` / `rename` / `delete` / `copy` / `move` | `StorageEntry` 或确认结果 | 成功后宿主通知本地来源缓存失效 |
| `upload` | `StorageUploadStep` | 同一操作分步调用；使用 `Params.Upload.Checkpoint/Response` 判断准备、续传与完成 |

目录 ID、文件 ID、根 ID、游标、版本和检查点均是不透明字符串。不要把 `/`、`0`、数字强转或本地路径当作远端身份；根目录必须使用 `StorageSource.RootID`。`List` 返回 `Total: -1` 时表示未知总数，继续读取只依赖 `HasMore` 和非空的新游标。

## 认证、续期和账号隔离

1. 用户在账号中心创建或选择账号，宿主把已声明字段传给 `configure`。
2. `verify` 返回稳定的远端 `Identity`、`RootID`、显示名称、凭据和 `ExpiresAt`，宿主以账号槽位和身份生成来源 ID。
3. 二维码登录由宿主保存 `Session` 并串行轮询；登录字段仍校验类型，但各登录方式自行校验必填输入，不会要求扫码前填写尚未取得的 Token。关闭、停用、删除或重新登录后，旧会话结果不能复活账号，旧快照也不会继续请求供应商。
4. 宿主在来源调用前后检查账号、插件版本、启用状态和授权版本；旧任务只会返回来源变化错误，不回退到 115 或 139。
5. 后台只在有效期接近阈值时触发 `refresh`，并使用账号级退避避免并发定时检查重复续期；续期失败不会连续请求，也不会覆盖仍有效的凭据。仅返回新有效期也会保存；同一身份省略有效期时保留原值，不把它清零。
6. 卸载插件时可以选择保留或擦除插件私有数据。保留后重新安装同一插件版本可恢复账号；擦除后账号与凭据不再恢复，旧来源失效。

网盘插件调用通用宿主工具时，账号限制到宿主实际登记的所属提供者；目录范围由项目原生绑定自动生成并按账号配对，本机访问还限制到该账号的 STRM 输出目录。其他网盘及其输出不因旧授权或插件自报提供者而开放；未来网盘复用同一规则，详见 [自动目录范围](plugin-host-tools.md#自动目录范围)。

`Credentials` 只发送给对应插件，配置读取接口对 `secret` 仅返回布尔状态。不要在插件日志、错误消息、`StorageEntry` 或 `StorageLink` 中写入 Token、Cookie、二维码会话或完整授权头。

业务操作中发生续期时，结果可额外返回 `data.storage_credentials: StorageCredentials`；宿主在同一账号调用锁内保存新凭据，保留身份、根目录和授权版本。普通业务操作不会触发来源重建，后续调用读取最新凭据。插件应在轮换后校验稳定 UID，不能用此字段切换账号。

## 上传和变更通知

上传不是把文件内容塞进 JSON/WASM。宿主按本地文件切片，首次 `upload` 调用的 `Params.Upload.Response` 为空；插件返回受限的 `PUT`/`POST` 请求、偏移、长度与检查点。宿主在发送字节前先保存检查点，再把不超过 64 KiB 的响应放入下一次 `upload` 的 `Params.Upload.Response`，并带回检查点。插件返回 `Entry` 表示完成，不能同时返回新的字节请求。单步偏移和长度有上限，缺少有效请求或检查点时不会写入任何字节。

- 检查点绑定账号、来源、授权版本、目标目录、本地文件路径、远端文件名、大小与修改时间；本地文件变化后在请求供应商前拒绝旧断点。宿主绑定包装不发送给插件，插件收到的仍是自身的不透明检查点；`null` 不作为有效检查点。
- 供应商返回已存在对象时用 `Reused: true`，宿主计为跳过，不重复上传。
- 网络错误、未知回执和检查点持久化失败不会自动重放写操作；用户重试时通过带检查点的 `upload` 调用执行供应商核验与恢复。
- `mkdir`、改名、移动、复制、删除和上传完成后，宿主调用 `NotifyStorageChanged`，按父目录和对象 ID 失效文件浏览、STRM、有声书和挂载索引。
- 远端变更事件也可调用同一通知入口；通知失败只记本地错误，不再次提交已成功的云端操作。

上传准备可以先返回 `StorageUploadStep{HashAlgorithm:"sha256"}`，由宿主计算并通过 `Upload.Hashes` 传回；当前支持 `sha256`、`sha1`、`md5`，同一算法重复请求会被拒绝。返回 `SaveCheckpoint:true` 和非空 `Checkpoint` 可以先持久化状态，再进入有副作用的元数据调用；断点恢复时 `Upload.Resuming` 为真，区别于本轮正常下一步。

供应商使用 multipart 时，在 `StorageHTTPRequest.Multipart` 声明 `FileField`、`FileName` 和有限文本 `Fields`。宿主将本地切片嵌入 multipart 并设置 Content-Length，文件内容不经过 WASM；普通 PUT/POST 切片保持兼容。传输 CDN 可声明 `*.example.com` DNS 后缀，通配符仅用于文件传输且不匹配根域或自定义端口；元数据 `http.fetch` 仍要求明确主机。

二维码可返回普通二维码文本，或不超过 200000 字符的 `data:image/png;base64,...` PNG；宿主验证格式后在原生账号中心展示图片，不把图片内容再次编码成二维码。

## 宿主侧安全边界

网盘插件不能直接操作项目数据库、宿主本地文件或其他账号。它只能在清单声明的权限下调用 `storage` 生命周期和 `http.fetch`；浏览器、FFmpeg、转存、整理等能力仍按各自宿主权限提供。宿主限制跨主机重定向时的 `Authorization/Cookie`，只接受声明的 HTTPS 主机和有限响应体。

提供者声明的能力是上限，不是自动实现：声明 `link` 不会获得 115/139 的专用签名、CAS、分享解析或事件语义；这些供应商特性必须在插件协议里实现。通用业务会在调用前再次检查能力，读写不支持时会明确返回 `unsupported`。

## 外部云盘 API

网盘插件安装后，账号中心自动显示“外部 API”，与原生网盘共用开关、Token、权限和调用地址布局。此开关默认禁用，每个账号独立保存 Token；外部 API Token 与网盘登录凭据分别管理。插件无需追加配置字段或 UI，不接收宿主的外部 Token。配置保存在现有加密账号记录中，随插件数据的保留、擦除和恢复处理。

管理入口 `GET/POST /api/accounts/{provider}/{account}/external-api` 需要项目登录，写入仍校验 CSRF。调用入口为 `POST /api/v1/storage/plugins/{provider}/{account}/{action}`，使用 `Authorization: Bearer <TOKEN>`。外部 Token 只对路径中的账号生效，请求体指定其他 `account_id/source_id` 会被拒绝。

| 权限 | action | 驱动能力 |
| --- | --- | --- |
| read | dir/list、dir/list-page、search | list |
| read | item | stat |
| read | download-url | link |
| write | dir/ensure | list、mkdir |
| write | rename | rename |
| write | copy、paste | copy |
| write | move | move |
| delete | delete | delete |
| upload | upload/file | upload |

列表使用 `parent_id/cursor/offset/limit/keyword/order/asc`，返回 `data.result` 下的 `items/has_more/next_cursor/total`；文件查询与直链使用 `id`，直链返回 `url/headers/expires_at`；重命名使用 `id/name`，复制、移动、删除使用 `ids`，目标目录用 `parent_id`。ID 与游标均保持字符串；省略父目录时使用该账号的真实 `RootID`。`dir/ensure` 的 `path` 为相对父目录的分段目录名；先验证全部段，再逐层读取已有目录，不遍历无关目录。

`upload/file` 接收 multipart/form-data，包含单个 `file` 和可选 `parent_id/name/account_id/source_id`。文件由宿主流式接收、限额检查、校验后交给统一上传能力；不会向调用方开放本地任意路径。复制、移动、删除及上传能力按插件声明检查，未声明返回 HTTP 501，不联系供应商；插件没有原生供应商专用的分片接口。

写操作可携带 `Idempotency-Key`，同一账号授权、动作、参数与编号重复提交复用已保存回执，同编号不同参数返回 HTTP 409；未知回执不自动重放。读取配置、鉴权失败与权限拒绝均不产生云盘请求。关闭外部 API、轮换 Token、改变权限、停用或删除账号及停用插件后，旧授权句柄会失效；更改外部配置不改变原生来源版本。

```sh
curl --request POST 'http://HOST:PORT/api/v1/storage/plugins/PROVIDER/ACCOUNT/dir/list' \
  --header 'Authorization: Bearer TOKEN' \
  --header 'Content-Type: application/json' \
  --data '{"limit":100}'
```


## 账号与任务附加设置（2026-11-12）

所有网盘使用宿主 `FlowpanStorageUI.Form`。驱动只声明字段与可选值，不能插入 HTML、CSS、JavaScript、自定义宽度或业务页面。以下声明会在原生账号中心显示版本选择和只读信息，在 STRM、自动上传等对应页面显示任务参数：

字段组件复用主程序的标签、输入框、按钮及主题边框。账号表单桌面两列、服务 URL 整行、手机单列；任务表单沿用所属页面容器。样式问题修改宿主共用组件，并检查其他提供者，不为每个插件重复加 CSS。

```json
{
  "fields": [
    {"key":"client_version","label":"客户端版本","type":"select","default":"v1","group":"连接设置","options_source":"client_versions"},
    {"key":"advanced","label":"高级设置","type":"boolean","default":false},
    {"key":"region","label":"服务区域","type":"select","options_source":"regions","depends_on":["client_version"],"visible_when":{"field":"advanced","equals":true}},
    {"key":"server_version","label":"服务端版本","type":"text","read_only":true}
  ],
  "task_fields": {
    "strm": [{"key":"channel","label":"访问线路","type":"select","default":"auto","options":[{"value":"auto","label":"自动"},{"value":"cdn","label":"加速"}]}],
    "upload": [{"key":"parallel","label":"并发数","type":"number","default":0,"hint":"0 使用驱动默认值。"}]
  }
}
```

字段规则：

- `fields` 是账号级参数，随账号加密保存；`task_fields` 仅接受 `strm`、`upload`、`organize`、`audiobook`、`fuse`，分别保存到对应任务的 `provider_options`。各任务独立，不修改账号默认设置。任务字段禁止 secret；认证密钥只能放在账号中。
- `default` 按字段类型校验，0、false 是有效默认值。`group` 是可选分组标题，不控制列数。`visible_when.equals` 支持字符串、数字和布尔值，依赖必须是本组已声明的非密钥字段，不允许循环依赖。
- 隐藏字段不参与必填校验，也不作为当前任务参数传给驱动。账号草稿保留已填值，重新显示后可继续使用；任务保存仅保留当前生效字段。密钥留空保留、null 显式清除。
- `read_only` 由宿主禁止编辑并在后端拒绝改写；只读字段不能同时声明用户必填，避免首次登录前缺少供应商信息而卡住。插件在 configure/verify/refresh/二维码确认的 `StorageAuth.Values` 中返回相应只读值；不能借此覆盖普通用户字段。信息与凭据均未变化的 verify 不重建来源版本。
- `select` 可使用静态 `options`，或用 `options_source` 标记动态选择。宿主发送 `Operation: "ui.options"`、`Context`、`Params.Field`；插件依据字段 key 返回 `[]pluginapi.Option`。`options_source` 是插件内部声明标识，不是外部 URL，也不会生成新的宿主路由。
- 动态读取携带本账号 `Settings/Credentials`；任务草稿位于 `TaskSettings`。`depends_on` 应列出影响选项的所有同组字段。宿主只在配置打开、条件显示或依赖变化时读取，250ms 合并变化；失败显示重试，同一草稿内缓存成功结果。切换账号、任务或关闭后，迟到结果不会覆盖新表单。
- 动态读取每次最多 8 秒、最多 200 个选项；显式保存时后端再次校验。失效旧值保持可见并提示重新选择，不自动替换；保存失败保留草稿。仅靠前端校验不会通过非法值。

运行调用中 `Settings` 是生效的账号值，`Context` 是当前业务，`TaskSettings` 是当前任务生效值。文件句柄捕获不可变参数；上传断点和签名直链缓存绑定任务参数，修改参数后不会复用旧上传会话或旧线路缓存。周期扫描与逐文件调用只做本地字段校验，不反复执行 `ui.options`。任务字段不能改变账号身份、来源根目录或远端对象 ID 的含义；此类差异必须通过账号配置隔离。

管理接口 `POST /api/storage/ui` 使用项目登录与 CSRF，接收 `source_id` 或 `provider/account`、`scope`、可选 `field/values/validate`。有 source_id 时只使用持久化来源关联的账号。默认只读取本地 schema，指定 field 时才向所属插件查询；返回值不含 secret。内置网盘和未声明扩展字段的旧插件返回空表单，原生业务保持原有布局。

仅扫码网盘增加版本等附加字段后，顶部账号、二维码与状态区仍保留原生扫码布局，附加设置显示在其下方。没有额外字段时不显示空标题或空白区域。联通插件继续仅扫码，不虚构供应商未支持的版本选择。

`tools/plugin-kit.py --storage` 已带账号动态版本、STRM 线路和上传并发的声明示例；HTTP 示例处理器包含 `ui.options`。使用新增字段的插件需要本轮更新后的宿主；旧宿主不会识别这些新增 UI 能力。验证包括 schema 拒绝、账号隔离、迟到响应、只读保护、默认值、真实 WASM 调用与持久化，以及四档宽度下的五类原生任务页面。

分享链接接管、原生转存协议和独立防护日志见 [插件分享接管与防护](插件分享接管与防护.md)。

## 浏览器与媒体复用

storage 处理器可以复用宿主 `browser.open/evaluate/close` 和 `media.status/probe/submit/task/result/cancel`。清单顶层与 definition.permissions 同时声明 browser.use、media.read、media.process 中实际需要的权限；浏览器还须声明 definition.browser.hosts。浏览器 profile 由宿主绑定当前账号，与其他账号和插件隔离。媒体只读取当前授权的本机输出，结果进入本插件私有目录；无本机绑定的扫码登录仍可调用浏览器。

这不开放 shell、任意命令或其他网盘写操作。health/migrate 不开放浏览器或媒体处理。依赖未就绪时通过 media.status 查询并由用户到设置下载；驱动不自行安装组件。完整方法和 SDK 示例见 [FFmpeg 媒体任务](plugin-host-tools.md#ffmpeg-媒体任务)。

## 增量事件与游标

真实支持增量列表的供应商可在 storage.capabilities 增加 changes。宿主发送 `StorageCall.Operation="changes"`，账号、凭据、SourceID、Revision 由宿主确定，Params 包含 cursor 和 limit。插件只实现本供应商协议，不接收其他账号来源。返回 `pluginwasm.StorageResult(pluginapi.StorageChanges{...})`：

```go
page := pluginapi.StorageChanges{
    Cursor: "next-opaque-cursor",
    Items: []pluginapi.StorageChange{{
        ID: "stable-provider-event-id", Kind: "move",
        ParentIDs: []string{"old-parent", "new-parent"},
        ObjectIDs: []string{"file-id"},
    }},
    HasMore: false,
}
return pluginwasm.StorageResult(page), nil
```

空 cursor 表示建立当前基线：必须返回非空 cursor、空 items、has_more=false，不回放历史。此后每页最多 100 条，每条至少一个父目录、最多 32 个父目录和 100 个对象。ID 与 cursor 保持不透明字符串，事件 ID 最长 512 字节，其他 ID 和 cursor 最长 4096 字节；同页 ID 不重复，有事件或 has_more=true 时 cursor 必须推进。移动、删除时需保留变化前的父目录信息，宿主不会额外请求云盘来补完整历史。

只有启用且已授权账号和目录的 file.changed 消费插件存在时，宿主才轮询声明了 changes 的来源。每来源每分钟最多一页，多个插件共用游标；has_more 不立即追页。失败按 2、4、8、16 分钟退避，服务重启保留冷却；来源 revision 变化后建立新基线。事件和游标在同一 SQLite 事务提交，投递失败只重放发件箱，不重做云盘写入。禁止用全量递归 list 冒充 changes，供应商没有增量 API 时不声明此能力。

项目发起并确认的原生文件操作无需驱动额外返回事件，宿主统一发布并失效 STRM、文件浏览、有声书和挂载缓存。驱动不接收宿主发件箱写入权限。消费端按来源、授权版本和目录检查后才收到事件；SDK 通过 inv.Request.Event.Data 读取新载荷，同时兼容旧 115 载荷，结构见 [通用网盘文件事件](plugin-host-tools.md#通用网盘文件事件)。

## 仪表盘与 FUSE 日志合同

声明了 definition.storage 的网盘插件自动接入宿主仪表盘，不需要逐品牌增加前端或注册额外动作。宿主在已通过权限与目标校验的 HTTP 发送点计数；实际重定向逐跳计数，连接失败计入已尝试请求，权限拒绝、直链缓存命中和宿主传输 CDN 文件内容不计为新的插件元数据 API 调用。

GET /api/dashboard 的 api_calls 合同保留 total、by_provider、by_path、by_account、by_account_path，并增加 provider_names。外部网盘的 by_provider 键使用 storage.id，显示名来自 storage.name；账号键为 storage.id + ':' + 宿主绑定的 Account，不能由插件请求参数覆盖。普通动作插件使用 plugin:{插件ID} 分组。端点记录只保留 HTTP 方法、站点、路径及查询参数名；请求头、正文、查询值和凭据不进入统计。计数覆盖当前主程序进程，重启后从零开始。

仪表盘刷新只读取本地计数、持久化 STRM 输出和挂载状态，不额外调用云盘、不验证凭据、不触发扫描。STRM 来源和 FUSE 挂载继续按不透明 SourceID 关联。FUSE 读取日志使用真实提供者标签（如 [fuse][wopan][read]），内置移动云盘保留 [139]；解析与缓存命中分别显示实际 api 数量。成功日志省略无意义的 status=0、空 code 与 error_type=<nil>，错误日志仅在存在时附加 HTTP 状态和错误代码，不记录签名地址、文件名或凭据。

完整自适应合同见 [插件通用接入合同](../sdk/plugins/INTEGRATION.md)。已安装插件在首个请求之前显示零计数，http.fetch、sdk.call、service.call 的实际 HTTP 发送均自动计数。网盘错误返回 pluginapi.StorageError，SDK 保留 code、status 和 message；FUSE 只记录业务码与状态，不输出完整错误正文。


## 账号绑定的外部服务与路径引用（storage 版本 1）

自建服务提供者可声明 `storage.endpoint_field`，指向账号表单中固定必填的 `url` 字段，并要求 `storage.account-endpoint: 1`。宿主只在网盘调用中开放该账号填写的 HTTP/HTTPS 服务地址、端口及路径前缀；其他账号地址、前缀外路径、普通动作入口不继承这项授权。原有 `http_hosts` 合同保持 HTTPS 和静态域名语义。元数据、内容读取及上传共用同一个边界，跨站重定向不携带认证信息。提供者应返回服务端代理链接，不能自行将任意 CDN 加入账号授权。

路径型存储可要求 `storage.path-refs: 1` 和 `storage.paths` 工具，使用 `pluginwasm.StoragePaths` 批量建立引用。`bind` 接收最多 1000 个规范绝对路径；`resolve` 按不透明 ID 查路径；`relocate` 原子更新目录及已知后代；`forget` 删除目标及已知后代。宿主绑定插件和账号，插件传入的 namespace 应包含服务、用户、用户根目录及挂载根目录身份。引用保存在 SQLite，账号显示名不参与隔离。列表回读复用已有引用，改名移动后继续使用同一 ID；在 OpenList 外部直接改名无法自动关联旧引用，需要重新扫描来源。

异步 move/copy 不能仅凭提交返回成功。插件须保存任务 ID、查询终态、定向核对目标；回执未知时保留检查点，重试先核验，不重新提交写操作。上传数据仍由宿主流式发送，插件返回同步接收请求及检查点，最终响应和文件大小通过核验后才返回 entry。新插件在旧宿主安装时应明确报告缺少上述能力。
