# 外部 115 存储 SDK

当前 SDK 版本：`0.2.0`

SDK 只调用 Flowpan 对外标准接口：

```text
/api/v1/storage/115/{driver}/{action}
```

不要让其他项目直接调用 `/api/mp/storage/115`，也不要复用 MP 插件事件密钥。

## 鉴权

先在 Flowpan 的 115 设置里启用“外部 API”，生成独立 Token，并按调用方需要勾选权限：

- `read`: 列表、查询、用量、下载直链。
- `write`: 新建目录、移动、复制、粘贴、重命名、星标。
- `upload`: 上传桥接能力。
- `delete`: 删除。

SDK 默认使用：

```http
Authorization: Bearer <external_api_token>
```

SDK 不会把 Token 放进 URL 查询参数。

## Driver

- `auto`: 推荐默认值。Flowpan 服务端按当前配置选择 OpenAPI 或 Cookie。
- `open`: 强制 OpenAPI。
- `cookie`: 强制 Cookie。

业务项目默认用 `auto`，只有排查链路差异或明确需要某条链路时才传 `open` / `cookie`。

SDK 支持两种切换方式：

- 设置客户端默认链路：后续不传 driver 的调用都走该链路。
- 单次调用覆盖链路：只影响当前请求。

## Go

路径：

```text
sdk/go/flowpan115
```

示例：

```go
package main

import (
	"context"
	"fmt"

	"github.com/yyllaa/Flowpan-light/sdk/go/flowpan115"
)

func main() {
	client := flowpan115.New("http://192.168.9.16:8088", "external-token")
	ctx := context.Background()

	client.SetDefaultDriver(flowpan115.DriverAuto)
	usage, err := client.Usage(ctx, "")
	if err != nil {
		panic(err)
	}
	fmt.Println(usage.Driver, usage.Result.Used, usage.Result.Available)

	// 单次强制 Cookie；同理可传 flowpan115.DriverOpen。
	dir, err := client.EnsureDir(ctx, flowpan115.DriverCookie, 0, "test")
	if err != nil {
		panic(err)
	}
	fmt.Println(dir.Result.CID)

	openClient := client.WithDefaultDriver(flowpan115.DriverOpen)
	page, err := openClient.ListPage(ctx, "", flowpan115.ListPageRequest{
		CID:     dir.Result.CID,
		Offset:  0,
		Limit:   100,
		ShowDir: flowpan115.Bool(true),
	})
	if err != nil {
		panic(err)
	}
	fmt.Println(page.Result.Total)
}
```

常用方法：

- `Usage`
- `EnsureDir`
- `ListDir`
- `ListPage`
- `Search`
- `Item`
- `DownloadURL`
- `MoveCheckConflict`
- `Move`
- `Copy`
- `Paste`
- `Rename`
- `Star`
- `Delete`
- `UploadFile`
- `UploadInit`
- `UploadStart`
- `UploadResume`
- `UploadListParts`
- `UploadPartURL`
- `UploadComplete`
- `Raw` / `Call`: 新接口或非封装接口的兜底调用。

错误处理：

```go
var apiErr *flowpan115.APIError
if errors.As(err, &apiErr) {
	fmt.Println(apiErr.StatusCode, apiErr.Code, apiErr.Message)
}
```

## Python

路径：

```text
sdk/python/flowpan115.py
```

示例：

```python
from flowpan115 import Flowpan115Client, DRIVER_AUTO

client = Flowpan115Client("http://192.168.9.16:8088", "external-token")

client.set_default_driver(DRIVER_AUTO)
usage = client.usage()
print(usage.driver, usage.result["used"], usage.result["available"])

# 单次强制 Cookie；同理可传 driver="open"。
dir_res = client.ensure_dir("test", driver="cookie")
cid = dir_res.result["cid"]

open_client = client.with_driver("open")
page = open_client.list_page(cid=cid, limit=100, show_dir=True)
print(page.result["total"])
```

## 上传建议

普通文件管理项目优先使用：

1. `upload_init`
2. `upload_start` / `upload_resume`
3. `upload_part_url`
4. 调用方把分片上传到返回的对象存储 URL
5. `upload_complete`

`upload_file` 只适合 OpenAPI 且文件已经在 Flowpan 服务端本地路径上的场景。

### 上传会话约束

`upload_init` 返回的 `session_id` 必须随 Session 一起保存，并用于后续
开始、续传、查询分片、获取分片 URL 和完成请求。不要修改服务端返回的
目标 CID、目标对象、回调或 `upload_id`。服务重启或会话过期后，旧 Session
需要重新执行 `upload_init`。

Go 和 Python SDK 还提供 typed upload 方法，使用强类型 Session 和 Part
对象，避免调用方漏传 `session_id` 或误修改服务端字段：

- Go：`UploadInitTyped`、`UploadStartTyped`、`UploadResumeTyped`、
  `UploadListPartsTyped`、`UploadPartURLTyped`、`UploadCompleteTyped`
- Python：`upload_init_typed`、`upload_start_typed`、`upload_resume_typed`、
  `upload_list_parts_typed`、`upload_part_url_typed`、
  `upload_complete_typed`

### 网络重试

默认只重试临时网络错误和 408、425、429、500、502、503、504，且动作限
定为查询、冲突检查、分片状态查询和分片 URL 获取。移动、复制、粘贴、
重命名、删除、上传初始化和完成上传不会自动重试。调用方如能确认操作
具备幂等性，可以自行配置重试策略。

## 调用约束

- 不要操作未授权目录；外部项目建议统一在自己的业务根目录下运行。
- 批量删除、移动、复制前先确认 `ids` 和 `parent_id`，避免误操作。
- 长任务调用方自己做重试；非幂等操作重试前先重新查询目标状态。
- Token 只放在服务端配置或密钥管理里，不写进前端代码。
