# 插件分享接管与防护

网盘插件可在原生“转存下载”接管自己声明的分享链接。链接识别、账号选择、目录选择、去重、排队与任务记录由宿主提供；插件只实现供应商的分享查询和接收协议。

## 声明链接

在插件 `definition` 中声明确切网络域名，并在 `definition.storage` 中增加 `share` 能力和 `share_links`。以下为现有网盘定义中需要追加的片段：

```json
{
  "http_hosts": ["share.example.com"],
  "storage": {
    "capabilities": ["list", "stat", "share"],
    "share_links": [
      {"host":"share.example.com","path_pattern":"^/s/[A-Za-z0-9]+/","query_keys":["code"]}
    ]
  }
}
```

`host` 必须是确切小写域名，不接受通配符、IP、端口和内置 115/139 域名，也必须出现在 `http_hosts` 的确切域名中。`path_pattern` 是从 `^/` 开始的 Go RE2 表达式，长度上限 256；匹配前缀成为规范路径，后面的 APP 唤起文案会被丢弃。规则应完整覆盖资源标识与结尾分隔符，避免错误截断。`query_keys` 是必须保留的参数白名单，其余查询参数与 fragment 不进入转存任务；链接必须使用 HTTPS。

宿主先从粘贴文字抽取链接，再在本地匹配，不运行插件、不访问云盘。同一个链接只处理一次。一个域名上的同一路径被多个提供者认领时拒绝处理；插件停用后仍保留已安装声明，避免链接被误投到 115 离线下载。卸载并清除数据后不再认领；卸载保留数据时保留停用的占位声明，避免误投其他网盘。未知域名沿用项目现有普通下载规则，插件不能认领所有 URL。

## 实现供应商处理器

在 `pluginwasm.Handlers.Storage` 中处理：

| Operation | 输入 | `pluginwasm.StorageResult` 返回值 |
| --- | --- | --- |
| `share.resolve` | `Params.Share.URL/Password`、`Params.ParentID` | `pluginapi.StorageShareInfo`，含分享 ID、名称和条目 ID；可用 `Context` 保存供应商查询上下文 |
| `share.save` | 原查询结果位于 `Params.Share.Info`，目标是 `Params.ParentID` | `pluginapi.StorageShareReceipt`；同步成功必须 `Done:true`，异步接收必须返回非空 `TaskID` |
| `share.status` | `Params.Share.TaskID` | 相同回执结构；只查询已提交任务，禁止重新提交 |

没有远端状态接口的同步供应商只需实现前两项。宿主不会调用已同步完成任务的 `share.status`。返回值通过标准 `StorageResult` 封装，账号凭据、稳定来源 ID 与当前授权校验沿用网盘驱动协议。

写入回执不明确时，任务进入“中断”，不自动重发。供应商业务失败也不能用隐式重试重复接收。宿主在写入前保存任务状态，按账号串行排队；任务与来源授权版本、分享链接、目标目录绑定。已有成功记录在“跳过重复”开启时复用；进行中和未知回执始终拦截重复提交。云端已确认转存后，即使缓存通知或整理失败，也不会重新接收。清除记录后会失去对应去重依据，应先核对远端文件。

分享查询上下文只保存在服务端任务数据库，不返回原生任务列表。原生页面只显示已启用且声明 `share` 的插件；未登录、缺少目录或不支持的链接会在提交前提示。自动整理还要求供应商具备 `mkdir`、`move`，并配置独立整理输入与输出；联通当前没有 `move`，不显示此选项。

## 管理接口

接口均使用项目登录；写操作校验 CSRF。

- `GET /api/transfer/storage/providers`：提供者及可用来源。
- `GET/POST /api/transfer/storage/config?source_id=SOURCE`：账号独立转存设置。
- `POST /api/transfer/storage/submit?source_id=SOURCE`：设置字段加 `text`。
- `POST /api/transfer/storage/delete?source_id=SOURCE` 和 `/resume`：正文 `{source_id,id}`；账号必须与任务一致。`resume` 只查询尚未确认的异步回执。
- `POST /api/transfer/parse` 与 `GET /api/transfer/tasks`：继续使用统一识别与统一任务列表。

任务保存在 `config/link_transfer_plugins.db`。账号删除、停用、身份变化及插件替换后，旧句柄在下一次调用时失效；历史任务保留供核对，不在启动时自动重放云端写入。

## 防护与日志

WASM 不获得宿主文件系统、环境变量、进程执行或任意网络访问。插件需要声明能力，运行时再检查当前安装状态、安装包版本、实时授权与当前账号、目录范围。停用或替换后，正在运行的插件下一次宿主调用也会被拦截。

网盘插件的宿主工具范围绑定其实际提供者、来源和账号，范围按账号从项目原生配置自动生成，不要求用户另选目录。本机读取额外限定在其账号已保存的 STRM 输出目录；运行中的调用也实时核对映射，其他网盘目录、项目配置与日志不纳入范围。越界请求记入 `scope_denied` 防护日志。转存、上传和整理继续走项目原生流程，STRM 写入与清理由宿主根目录和摘要检查保护。合同与边界说明见 [插件宿主工具 API](plugin-host-tools.md#账号与目录配对)。

HTTP 请求受域名、方法、请求大小、响应大小、跳转次数与超时约束。跨站 GET/HEAD 跳转只保留浏览所需标准头，删除账号凭据和自定义鉴权头；跨站写入跳转直接拦截，避免请求体与密钥被重发到另一个域名。检查类动作保持只读，私有数据键与宿主保留数据隔离。单次执行保留现有内存、时间与宿主调用次数上限。

“插件管理 → 防护日志”独立于运行记录和普通日志。相同插件、规则、能力、域名、运行模式合并计数，最多保留 1000 项，单次显示最近 200 项。只记录宿主规则、域名、时间与次数，不记录路径、查询参数、请求正文、Cookie、Token 或插件自带错误文案。普通接口失败不伪装为越权事件。

`GET /api/plugins/protection` 支持 `plugin_id` 过滤；`POST` 正文 `{clear:true}` 清理日志。卸载保留数据时保留审计；显式选择同时擦除插件数据时移除其防护日志。此日志记录运行期拦截，不是对任意第三方插件可信性的证明。
