# 外部 115 存储 API 标准

该接口供 Flowpan 外部项目调用 115 网盘能力，和 MoviePilot 插件接口隔离，不复用 `strm_event_notify_token`。

## 启用配置

核心配置字段：

- `external_api_enabled`: 是否启用外部 API。
- `external_api_token`: 外部调用密钥。
- `external_api_scopes`: 权限，支持 `read,write,upload,delete` 或 `admin`。为空且启用时默认 `read,write,upload,delete`。

`/api/config/core` 的 `basic` 对象也支持透传：

- `EXTERNAL_API_ENABLED`
- `EXTERNAL_API_TOKEN`
- `EXTERNAL_API_SCOPES`

## 鉴权

推荐使用：

```http
Authorization: Bearer <external_api_token>
```

兼容：

- `X-Flowpan-External-Token`
- `X-Flowpan-Token`
- 查询参数 `token`

不要使用 MP 插件的事件密钥。

## 路由

统一前缀：

```text
/api/v1/storage/115/{driver}/{action}
```

Go / Python SDK 见：[外部115存储SDK.md](./外部115存储SDK.md)。

`driver`：

- `open`: 强制 OpenAPI。
- `cookie`: 强制 Cookie。
- `auto`: 配置启用 OpenAPI 且已授权时走 OpenAPI，否则走 Cookie。

全部接口使用 `POST`，响应统一为：

```json
{
  "code": 200,
  "data": {
    "driver": "open",
    "result": {}
  }
}
```

## 能力

读权限 `read`：

- `dir/list`
- `dir/list-page`
- `search`
- `item`
- `usage`
- `download-url`

写权限 `write`：

- `dir/ensure`
- `move/check-conflict`，仅 Cookie
- `move`
- `copy`
- `paste`
- `rename`
- `star`

删除权限 `delete`：

- `delete`

上传权限 `upload`：

- `upload/file`，仅 OpenAPI 本地文件直传
- `upload/init`
- `upload/start`
- `upload/resume`
- `upload/list-parts`
- `upload/part-url`
- `upload/complete`

上传会话接口兼容直接传 session 对象，或传 `{ "session": ... }`。
