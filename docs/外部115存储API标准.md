# 外部 115 存储 API 标准

该接口供外部项目调用 Flowpan 默认 115 配置中的网盘能力，使用独立的外部 API Token。

## 启用配置

核心配置字段：

- `external_api_enabled`: 是否启用外部 API。
- `external_api_token`: 外部调用密钥。
- `external_api_scopes`: 权限，支持 `read,write,upload,delete` 或 `admin`。为空且启用时默认 `read,write,upload,delete`。

`/api/config/core` 的 `basic` 对象也支持透传：

- `EXTERNAL_API_ENABLED`
- `EXTERNAL_API_TOKEN`
- `EXTERNAL_API_SCOPES`

## 鉴权

推荐使用：

```http
Authorization: Bearer <external_api_token>
```

兼容：

- `X-Flowpan-External-Token`
- `X-Flowpan-Token`
- 查询参数 `token`

不要使用 MP 插件的事件密钥。

## 路由

统一前缀：

```text
/api/v1/storage/115/{driver}/{action}
```

Go / Python SDK 见：[外部115存储SDK.md](./外部115存储SDK.md)。

`driver`：

- `open`: 强制 OpenAPI。
- `cookie`: 强制 Cookie。
- `auto`: 配置启用 OpenAPI 且已授权时走 OpenAPI，否则走 Cookie。

全部接口使用 `POST`，响应统一为：

```json
{
  "code": 200,
  "data": {
    "driver": "open",
    "result": {}
  }
}
```

## 能力

读权限 `read`：

- `dir/list`
- `dir/list-page`
- `search`
- `item`
- `usage`
- `download-url`

写权限 `write`：

- `dir/ensure`
- `move/check-conflict`，仅 Cookie
- `move`
- `copy`
- `paste`
- `rename`
- `star`

删除权限 `delete`：

- `delete`

上传权限 `upload`：

- `upload/file`，仅 OpenAPI 本地文件直传
- `upload/init`
- `upload/start`
- `upload/resume`
- `upload/list-parts`
- `upload/part-url`
- `upload/complete`

上传会话接口兼容直接传 session 对象，或传 `{ "session": ... }`。

写请求可借助 `Idempotency-Key` 保存并复用回执。支持 `dir/ensure`、`copy`、`paste`、`move`、`rename`、`star`、`delete`、`upload/file`、`upload/init` 和 `upload/complete`。网络中断后继续使用原编号、原参数和相同的实际链路。回执状态与 HTTP 状态码见[写请求回执](外部139存储API.md#重试与请求回执)。
