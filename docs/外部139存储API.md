# 外部 139 存储 API

在“账号中心 → 139 网盘”选择账号后，打开该账号的“外部 API”，启用、生成 Token、选择权限并点击“保存外部 API”。每个 139 账号单独保存密钥；账号切换、重新扫码和服务重启不会改用其他账号的密钥。更换 Token 后，旧 Token 和旧上传会话立即失效。停用外部 API、停用账号或删除账号后停止接受外部调用。

调用方式与 115 一致：POST JSON，独立 Token，读取／写入／上传／删除权限，返回 `{code,data:{driver,result},msg}`。139 的 `driver` 为 `139`。业务参数错误沿用现有 API 的 HTTP 200、`code:400`；鉴权失败为 HTTP 401，权限不足为 HTTP 403。

## 地址与认证

- 固定账号：`/api/v1/storage/139/{账号ID}/{操作}`。账号 ID 和完整地址可在外部 API 配置中查看。
- 按密钥识别账号：`/api/v1/storage/139/auto/{操作}`。
- 推荐请求头：`Authorization: Bearer TOKEN`。
- 兼容 115 的 `X-Flowpan-External-Token`、`X-Flowpan-Token` 和 `?token=TOKEN`；使用请求头可避免密钥进入 URL 历史。
- 这些入口使用外部 Token，无需网页登录。配置读取和保存仍需管理页登录及写入时的 CSRF 校验。
- 请求体中的 `account_id` 和 `source_id` 仅作一致性检查，不能覆盖 Token 绑定的账号。

139 文件和目录 ID 是不透明字符串，包括看似纯数字的长 ID。全部按字符串传递，根目录为 `/`，不沿用 115 的数字 `0`。请求字段支持 `cid_text`、`id_text`、`target_cid_text` 别名。

## 操作

| 操作 | 权限 | 主要输入 | 结果 |
| --- | --- | --- | --- |
| `dir/list`、`dir/list-page` | read | `parent_id`，可选 `limit`、`cursor`、`order`、`asc` | 一页 `items`、`has_more`、`next_cursor`、`total` |
| `search` | read | 同上，增加 `keyword` | 当前目录内按名称过滤；逐页读取 |
| `item` | read | `id`，省略时为根目录 | 文件或目录信息 |
| `usage` | read | `{}` | `total`、`free`、`used` 字节数与使用百分比 |
| `download-url` | read | `id`，可选 `user_agent` | `url`、`headers`、`expires_at` |
| `dir/ensure` | write | `parent_id`，`path` 或 `name` | 复用或逐层建立目录，返回最后一级目录 |
| `move/check-conflict` | write | `ids`、`parent_id` | 目标目录中的同名 `conflicts` |
| `copy`、`paste`、`move` | write | `ids` 字符串数组、`parent_id` | 原生网盘操作完成后返回成功 |
| `rename` | write | `id`、`name` | 改名结果 |
| `delete` | delete | `ids` 字符串数组 | 放入回收站；根目录不接受删除 |
| `upload/file` | upload | multipart 文件与目标目录 | `{entry,reused}`；单文件最多 2 GiB |
| `upload/init` | upload | `parent_id`、`name`、`size`、`sha256` | `{session,parts,reused,complete}` |
| `upload/start`、`upload/resume`、`upload/list-parts`、`upload/part-url` | upload | `session`，可选 `part_number` | 原上传会话的分片 URL 批次 |
| `upload/complete` | upload | `session` | 完成上传并返回已完成会话 |
| `upload/heartbeat` | upload | `session` | 延长本次直传活动状态，返回 `active`、`expires_in` |
| `upload/cancel` | upload | `session` | 结束本地上传活动状态；不删除云端文件 |

目录列表使用 139 游标分页，两个列表入口都返回一页。`has_more:true` 时继续提交 `next_cursor`，同时保持目录、排序、页大小和关键词一致；不要用任意 offset 跳页。`total:-1` 表示还未读取到总数。游标绑定账号和目录，不能跨账号复用。

单次复制、移动、删除最多 100 项。同盘原生复制不经服务器下载。云端操作失败时不自动重放创建或复制。139 未提供的 115 专有操作（例如收藏、115 Cookie/OpenAPI 切换）不映射为其他操作。

## 重试与请求回执

139 与 115 的外部写接口支持可选请求头 `Idempotency-Key`。调用端为一次逻辑操作生成一个 UUID 并持久保存，断线后使用同一个编号、同一组参数重试。支持 `dir/ensure`、`copy`、`paste`、`move`、`rename`、`delete`、`upload/file`、`upload/init` 和 `upload/complete`；115 的 `star` 也支持。未传此头时沿用原调用方式。

- 编号最长 128 字节，不含空白字符。同一账号授权内，同一个编号只对应一种操作和参数；更换参数或操作会返回 HTTP 409。不同账号独立记录。
- 服务在云端写入前保存待执行记录，执行后保存成功或失败回执。并发重试共享原结果；服务重启后仍可重取已完成回执。重复上传 multipart 仍需再次发送文件，服务按目标目录、名称、大小和实际接收内容的 SHA256 判断是否是同一次上传，再复用原云端结果。
- 原请求尚未结束时，重复请求最多等待 30 秒，仍不明确则返回 HTTP 409 和 `Retry-After: 1`。进程在云端写入前后中断而留下不明确记录时，不自动再次执行；先检查目标，继续使用原编号查询。
- 成功和失败的完整回执保留七天，过期返回 HTTP 410。请求指纹继续保留，旧编号不会被当成新写入执行。回执存储在 `/config/external_api.db`，随原 `/config` 一起保留。
- `upload/init` 回执中的分片 URL 可能已过期。重取初始化回执后，使用其中的原 `session` 调用 `upload/resume` 或 `upload/part-url` 刷新地址。

`dir/ensure` 另外按账号、授权版本、父目录和名称缓存五分钟，最多 512 条；同一目录的并发冷请求合并为一次查询／创建。通过项目改名、移动或删除后失效该账号缓存。在官方客户端修改目录后，最多等待缓存到期；目录已存在或命中缓存时不产生新建事件。

## 调用示例

```bash
curl -X POST 'http://HOST:8080/api/v1/storage/139/auto/dir/list-page' \
  -H "Authorization: Bearer $FLOWPAN_API_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"parent_id":"/","limit":100}'

curl -X POST 'http://HOST:8080/api/v1/storage/139/auto/upload/file' \
  -H "Authorization: Bearer $FLOWPAN_API_TOKEN" \
  -F 'parent_id=/' -F 'file=@./example.flac'
```

以下 Python 函数可复用到外部项目，使用标准库：

```python
import json
import os
import urllib.request

def call139(action, payload, request_key=None):
    base = os.environ["FLOWPAN_BASE_URL"].rstrip("/")
    request = urllib.request.Request(
        base + "/api/v1/storage/139/auto/" + action,
        data=json.dumps(payload).encode("utf-8"),
        headers={
            "Authorization": "Bearer " + os.environ["FLOWPAN_API_TOKEN"],
            "Content-Type": "application/json",
        },
        method="POST",
    )
    if request_key is not None:
        request.add_header("Idempotency-Key", request_key)
    with urllib.request.urlopen(request, timeout=120) as response:
        result = json.load(response)
    if result["code"] != 200:
        raise RuntimeError(result.get("msg", "139 API failed"))
    return result["data"]["result"]

page = call139("dir/list-page", {"parent_id": "/", "limit": 100})
```

## 秒传与分片续传

1. 对实际文件计算 SHA256，向 `upload/init` 提交文件名、大小、SHA256 和目录。139 使用 SHA256，115 的 SHA1 不通用。
2. 返回 `reused:true`、`complete:true` 时已命中秒传，无需 PUT 文件数据或再完成上传。
3. 未命中时，按返回的 `parts` 上传对应分片。`partNumber` 从 1 开始；不大于 30 GiB 的文件每片 100 MiB，超过 30 GiB 每片 512 MiB；最后一片为剩余字节。
4. 初次和后续 URL 批次最多 100 片。调用 `upload/part-url` 等入口并传入下一批的 `part_number` 获取后续地址；地址过期时重新请求同一批次。`upload/list-parts` 返回该批次计划分片和地址，不代表云端已确认的分片清单；调用端应保存自己的成功分片记录。
5. 上传完全部分片后，向 `upload/complete` 原样提交 `session`，保存返回的完成会话。完成回执因网络中断丢失时，服务会核验同一个文件 ID。
6. `session` 绑定账号、来源版本、目标目录、文件 ID、上传 ID、名称、大小和哈希，并带独立服务端签名，有效期七天。原样保存和回传；修改内容或混用账号会拒绝。恢复只取原会话的分片地址，不新建文件。

`upload/file` 在读取正文前检查上传占用、声明的大小和暂存空间；忙碌返回 HTTP 409，超限返回 HTTP 413，空间不足返回 HTTP 507。未知长度的流在接收中继续检查空间。正文直接写入项目暂存目录的一份文件并同步计算 SHA256，不先在系统临时目录保存另一份。完整接收后交给现有 139 上传驱动；可命中秒传，成功、取消或出错都清理本次暂存并释放占用。需要客户端控制分片进度或中断恢复时使用 `upload/init` 与后续分片接口。

## 直传活动与书库扫描

`upload/init` 创建直传活动记录，`upload/resume`、取分片地址和 `upload/heartbeat` 延长有效期。文件数据直接 PUT 到 139 时，Flowpan 看不到 PUT 进度；调用端应在上传期间每分钟发送一次 `upload/heartbeat`。活动心跳有效期五分钟，重启后沿用尚未到期的记录。完整上传后调用 `upload/complete`，中止时调用 `upload/cancel`。完成和取消立即结束活动，已关闭会话的旧心跳不能重新开启；心跳中断五分钟后不再阻塞扫描。秒传命中后立即结束活动。

活动仅影响同一账号且目标目录位于该有声书绑定目录内的书库；子目录通过已有本地索引判断，其他文件夹、其他账号继续独立扫描。新目录尚未进入索引时，最终完成事件仍进入原定向变更队列。密钥轮换、账号禁用或授权版本变更后，旧会话的活动失效。活动记录只控制上传期间的等待，不把探测失败当成仍在上传。

## 调用日志

115 和 139 外部调用日志分别记录账号标识、操作、HTTP 状态、`api_code`、耗时及 `cloud_requests`。后者按本次请求真正发出的网盘 API 尝试计数，包含失败请求和重试，不包含分片 CDN PUT。命中目录缓存或读取已完成回执时可为 0。日志不记录 Token、请求正文和签名直链。

外部写入复用现有 139 驱动和定向变更队列，完成后的目录变化按已绑定的 STRM／有声书目录处理。Token 不出现在普通账号列表或运行日志中。
