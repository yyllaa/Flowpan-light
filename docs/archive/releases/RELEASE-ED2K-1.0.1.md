# 115 ED2K 1.0.1

- 手机按钮统一 36px 高、13px 字号，复制和删除与大小、账号、状态同排。
- 收紧标题、说明、勾选栏和记录间距；未勾选时收起批量操作，长文件名最多两行并保留完整标题。
- 记录列表独立滚动，筛选与分页保持可见；已选链接按需展开。
- 保留生成、授权、复制、导出、停止、继续及删除确认流程；插件独立安装与更新。

本次配套主程序为 `2026.11.16-ed2k-ui`。镜像按原有单独导出方式交付，宿主仍按单文件、单连接读取，并复用每文件 256 KiB 缓冲。

先导入配套主程序镜像并启动，再在插件管理中刷新已有插件源、检查更新，将 115 ED2K 更新到 1.0.1。也可直接导入本 Release 的 `ed2k-1.0.1.zip`。插件包附 SHA-256，清单包含本版更新说明。

前端检查 765 项通过；浏览器检查覆盖复制、导出、删除确认、停止与继续、搜索恢复、文件浏览入口及跨插件结果选择，并验证 1440、768、390、320 像素布局。
