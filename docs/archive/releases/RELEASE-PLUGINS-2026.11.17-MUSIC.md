# 音乐刮削 1.0.0

支持本地与网盘音乐标签、封面和歌词，复用主程序的暂存、探测、无损封装、校验回写和备份恢复。

- 单文件串行、默认 3 秒网盘间隔；iTunes 4 秒、MusicBrainz 2 秒。限流后持久化等待，定时任务沿用进度，不叠加批次。
- 文件指纹与策略指纹增量跳过，共享元数据和封面缓存，待确认结果也复用。标题和歌手严格匹配；版本或专辑存在歧义时等待确认。
- 定时扫描可配置 cron，真实进度使用同一任务显示。查询记录保留在插件详情，减少任务中心噪声。
- 本地默认保留原件另存；网盘可选择保留两份或备份后替换，并从记录恢复原件。网盘替换会产生新文件 ID，非原子操作。
- 不把整首音乐放入 WASM 内存；宿主暂存一首处理，完成后释放音频暂存，备份与有限封面缓存按规则保留。

需要先安装主程序 `2026.11.17-music-runtime` 或包含相同合同的后续版本。插件启动时会检查必要合同、FFmpeg 和 FFprobe。源站不保证每首音乐都有结果。

3000 文件为模拟压力测试，并非真实网盘批量写入；真实 115 测试只在新建隔离目录中使用副本，不修改原音乐库。详细验证记录随交付提供。

音乐刮削插件已下架。本记录保留当时的发布内容，仍可使用的通用能力见 [长批次任务与媒体处理合同](../../plugin-batch-media.md)。SDK 同步公开续执行、二进制封面请求、歌词与封面无损封装合同。

已验证：3000 文件、100 个不同查询的模拟首次产生 100 次元数据请求，第二轮无下载、无查询、无上传。真实 115 副本完成封面和歌词写入、音频数据 SHA-256 一致、备份与恢复；三首本地样本中两首自动写入，一首待确认，第二轮三首复用且无新文件任务。另验证了 429 冷却、重启续执行、秒传回执缺失 ID 的唯一文件查回与哈希校验、哈希不符禁止提交。
