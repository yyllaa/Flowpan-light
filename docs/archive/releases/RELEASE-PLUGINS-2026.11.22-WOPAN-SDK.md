# 联通云盘 0.2.5 与插件开发包

- 联通云盘保留业务错误码和真实 HTTP 状态，修复错误解释及 WASM 返回过程中错误类型丢失。错误消息继续脱敏，批量目录复用、二维码登录和续期流程沿用现有实现。
- 插件开发合同补齐整盘与明确目录授权、账号隔离、撤权、冻结任务、新目录事件及插件管理和原生配置的边界。
- 请求合同明确永久失败停止重试、临时读取有限退避、未知写回执查询原任务，以及保留 `pluginapi.StorageError` 的业务码与 HTTP 状态。
- 独立开发包附带 `INTEGRATION.md`；SDK 同步交互菜单、分钟级定时枚举和资源描述字段，并固定已验收的主程序与 SDK 摘要。发布索引必须绑定完整源码提交。
- 页面模板改为通用动作与任务状态示例；交互合同同步企业微信纯文本资源分页规则。

本次发布提供联通插件、通用 SDK、插件示例和文档。主程序镜像继续单独交付；原生整理、139 及主程序授权实现的修复通过主程序镜像更新生效。

联通插件用户刷新已有插件源后更新到 0.2.5。其他插件的版本及安装包保持原值。新插件遵循 [通用接入合同](../../../sdk/plugins/INTEGRATION.md) 和 [固定宿主发布流程](../../../sdk/plugins/RELEASE.md)，在 `sdk/plugins` 或仓库生成器中开始独立开发。
