# OpenList 0.1.0 / 插件开发包 2026.11.24

- 新增 OpenList 网盘：账号密码（可选两步验证码）或 Token，多服务、多用户及同名账号隔离。
- 分页浏览、详情、Range 读取、STRM、有声书、整理、FUSE 来源读写，以及建目录、改名、移动、复制、删除和流式上传。
- 引用跟随本插件改名和移动；异步任务核验终态，未知写回执不自动重复提交。
- 公共 SDK 增加账号服务端点及持久路径引用合同，插件表单沿用宿主公共组件。

先更新到已单独交付的 `2026.11.23-openlist-plugin` 主程序镜像，再刷新现有插件源。旧版缺少 `storage.account-endpoint:1` 和 `storage.path-refs:1`，安装时会要求更新。主程序源码与镜像不在本次公开上传范围。

已使用官方 OpenList 4.2.9 Local 驱动和最终 WASM 包验证登录、账号隔离、路径前缀、分页、Range、上传、异步复制、重启持久化及 STRM 读取。FUSE 验证到来源读写层；外部云盘驱动与系统 FUSE 挂载未逐一验证。其他插件保持原版本。
