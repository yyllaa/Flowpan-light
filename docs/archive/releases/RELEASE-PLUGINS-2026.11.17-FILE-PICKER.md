# 音乐刮削 1.0.3 / 通用来源与目录选择

- 音乐来源读取宿主统一账号目录及当前授权，支持 115、139、插件网盘与本机目录，提供者名称区分同名账号。
- 单选来源与目录选择沿用项目控件，支持浏览已授权目录及手填，切换来源后清空旧目录，保留不透明目录 ID。
- 目录浏览不创建任务，不执行刮削或上传；逐首处理、缓存、请求间隔、定时与回写流程保持。
- 独立 SDK 和通用声明示例同步更新，后续插件可自行声明使用。

配套主程序 `2026.11.17-plugin-file-picker` 通过离线镜像包交付。先更新主程序，再在插件市场更新音乐刮削到 1.0.3。清单要求 `ui.file-picker: 1`，旧宿主保留已安装版本并显示具体缺项。
