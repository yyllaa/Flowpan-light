# 插件更新：TMDB 显示与手机布局

## 癫影 OpenAPI 1.3.10

- 分享结果中的 TMDB 编号使用完整数字，例如 TMDB 1257985，不再显示为科学计数法。
- 首次结果与缓存回执使用同一显示方式；缓存回执不重复发布。
- 发布参数中的数字编号沿用原合同。

## 115 ED2K 1.0.2

- 管理页按内容高度显示，少量记录的分页紧跟列表，减少上下留白。
- 记录较多时限制内容区高度，筛选、批量操作和分页保持可用。
- 真实生成任务与字节进度接入任务中心，查询动作保留在插件详细记录。
- 生成继续使用单文件、单连接连续读取与 256 KiB 缓冲。

先更新配套主程序 `2026.11.16-plugins-mobile-tmdb`，再刷新现有插件源并检查更新；也可直接导入本 Release 的插件 ZIP。主程序镜像单独导出。每个插件包提供 SHA-256，版本说明随清单发布。

公共页面 SDK 与插件页面文档同步提供 fitContent() 和可用高度合同。插件与 SDK 在公开目录独立测试、构建与校验。
